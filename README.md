# Algoritm för Meddelandeavkodning

Detta repository innehåller ett flödesschema som beskriver steg-för-steg-processen för att avkoda ett meddelande.

## Flödesschema



### Steg i processen:
1. **Ta bort Salt** – Rensar indatan från salt/brum.
2. **Dela upp i sifferpar** – Delar upp sekvensen i par om två siffror.
3. **Översätt med infogat alfabet** – Mappar sifferparen mot tecken.
4. **Lägg till mellanslag i meddelandet** – Formaterar meddelandet för läsbarhet.
